# Global Macroeconomics & Customer Demographic Analysis

This repository contains data analysis scripts, visualizations, and comparative findings joining macroeconomic regional indicators with individual customer banking profiles. The goal of this project is to evaluate the relationship between regional economic prosperity and customer financial metrics such as credit score, balance, tenure, and product adoption.
